Accessibility · Vue

A11y Scan Bookmarklet

In a 2018 UK government audit, the top automated accessibility tools detected about 30–40% of the 142 barriers tested. I built A11y Scan to make deeper testing easier while developing Vue components.

When Vue exposes component metadata, the bookmarklet groups findings by component and shows where each one sits in the component tree. It can also show the source file when available. Alongside axe-core and custom checks, it helps you inspect keyboard focus and run delayed scans for states like an open dialog or a validation error.
